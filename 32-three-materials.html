Lesson 32 — Geometry, materials & lights

Shape, surface and illumination: the three ingredients of every 3D look.

Geometry

A geometry is a bundle of arrays (attributes): position (vertices), normal (surface direction for lighting), uv (texture coordinates), and an optional index of triangles.

More segments = smoother and heavier. Triangles count against your performance budget.

Each additional light adds per-pixel cost. Prefer one key directional light, a hemisphere/ambient fill and an environment map (Lesson 34). Light intensities in modern Three.js are physically based: point and spot lights usually need intensities in the dozens, directional around 1–4.

Shadow checklist

  1. renderer.shadowMap.enabled = true
  2. light.castShadow = true
  3. mesh.castShadow = true on casters; mesh.receiveShadow = true on receivers
  4. Fit light.shadow.camera bounds tightly; raise mapSize for sharpness; tweak bias/normalBias for "shadow acne".
  5. Debug with new THREE.CameraHelper(light.shadow.camera).
ColorsThree.js works in linear color space and outputs sRGB by default. Hex colors you pass ("#ff0066") are interpreted as sRGB automatically. Textures that hold color need texture.colorSpace = THREE.SRGBColorSpace; data textures (normal/roughness maps) stay linear.

Exercises

  1. Build a row of 5 spheres with roughness 0 → 1, and another row with metalness 0 → 1.
  2. Add a SpotLight with a visible cone (SpotLightHelper) sweeping across the floor.
  3. Make glass: MeshPhysicalMaterial with transmission: 1, thickness, ior. Place colored objects behind it.
  4. Build a custom BufferGeometry for a flat grid and give it per-vertex colors.
  5. Build a simple low-poly "tree" by grouping a cylinder and cones (THREE.Group).
  6. Toggle shadows off and measure how the frame rate changes.

Checkpoint

Why is my MeshStandardMaterial object black?It's a lit material and there are no lights (and no environment map).
Roughness vs metalness?Roughness controls how blurred reflections are. Metalness decides whether the surface behaves like a metal (colored reflections, no diffuse) or a dielectric.
