Arrays: lists of values

A shopping list, the songs in a playlist, the messages in a chat, the scores in a game: programs are full of lists. In JavaScript, a list is called an array.

In this lesson you will

  • Create arrays, and read items by their index.
  • Add, remove and change items.
  • Loop through an array with for...of.
  • Search arrays with includes and indexOf, and combine them with join, slice and spread.
  • Write array types in TypeScript: number[], string[].

About 45 minutes.

Creating an array

An array is an ordered list of values, written in square brackets with commas between the items:

Each value in the array is called an element (or item). An array can hold any type of value, and any number of them, including none.

AnalogyAn array is like a row of numbered lockers. Each locker holds one thing, and the lockers are numbered in order, starting from 0.

Reading items by index

Arrays use the same numbering as string characters: the first item is at index 0.

Index012
Item"apple""banana""cherry"

For const days = ["Mon", "Tue", "Wed", "Thu"], what is days[days.length - 2]?

days.length is 4, so days.length - 2 is 2, and index 2 is "Wed" (counting Mon=0, Tue=1, Wed=2).

Useful array tools

The ... in [...words, ...more] is called spread. It means "spill out all the items of this array here". It's the easy way to combine or copy arrays.

Arrays can hold anything

Items can be any type, including other arrays. An array of arrays is a handy way to store a grid:

In JavaScript, you can also mix types in one array, like [1, "two", true]. It's allowed, but usually a sign of muddled data. TypeScript will help keep your arrays tidy.

Common mistakes
  • Off by one: the last item is arr[arr.length - 1], not arr[arr.length].
  • "Copying" with =: use [...arr] for a real copy.
  • Expecting push to return the array: it returns the new length. It changes the array in place.
  • Checking an empty array with if (arr): an empty array is truthy! Use if (arr.length === 0).

Mixed arrays and readonly

Two extras you'll see in real code. If an array really should hold two types, TypeScript writes that with | ("or"). And if a function shouldn't change an array it's given, mark the parameter readonly:

The (string | number)[] type means "an array where each item is a string or a number". You'll learn all about | types in the Union types lesson.

Another way to write itYou may see Array<string> instead of string[]. They mean exactly the same thing. The angle-bracket form is called a generic, which you'll learn about later.

Recap

  • An array is an ordered list: ["a", "b", "c"]. Indexes start at 0; .length is the count.
  • Change items with arr[i] = x. Add/remove with push/pop (end) and unshift/shift (start).
  • Loop with for (const item of arr).
  • includes, indexOf, join, slice, and spread [...a, ...b].
  • = doesn't copy an array. [...arr] does.
  • TypeScript: string[], number[]. Annotate empty arrays. Use readonly to prevent changes.
