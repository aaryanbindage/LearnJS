JavaScript is the language of the browser. In these lessons every JS example is runnable: edit it, and the output panel (right) updates. Use console.log() to see values.

Where JavaScript runs

You can also experiment in the browser DevTools Console, or with Node: node file.js.

Variables

Names: camelCase for variables and functions, PascalCase for classes/components, UPPER_SNAKE for true constants. Names can't start with a digit.

Exercises

  1. Predict then check: [] + [], [] + {}, "5" - 2, "5" + 2, true + true.
  2. Write a program that stores a name and age in variables and logs a sentence using a template literal.
  3. Convert the string " 42.5px " to the number 42.5.
  4. Explain why 0.1 + 0.2 !== 0.3 and write a safe comparison using Math.abs(a-b) < Number.EPSILON.
  5. Given const s = "Hello, World", produce "dlroW ,olleH" (hint: split, reverse, join).

Checkpoint

const vs let?Both are block-scoped. const can't be rebound; let can. Default to const.
|| vs ??|| falls back for any falsy value (0, "", false). ?? only for null and undefined.
