Lesson 34 — Textures, glTF models & environment

Photorealism comes from textures, imported models and image-based lighting rather than from more lights.

Textures

  • Power-of-two sizes (1024, 2048) are best for mipmaps; keep textures as small as quality allows. GPU memory ≈ width × height × 4 bytes × 1.33.
  • Use compressed GPU formats (KTX2/Basis) for big scenes via KTX2Loader.
  • Free PBR sets: ambientCG, Poly Haven. Free HDRIs and models at Poly Haven too.
  • Generate textures procedurally with CanvasTexture (below) or in shaders.

Environment lighting (IBL) and procedural textures (live)

An environment map lights and reflects every PBR material using a surrounding image. Here we use Three's built-in RoomEnvironment and draw our own checker texture on a canvas, so no files are needed.

For real HDRIs: new RGBELoader().load("studio.hdr", tex => { tex.mapping = THREE.EquirectangularReflectionMapping; scene.environment = scene.background = tex; }) (or EXRLoader, HDRLoader in newer releases).

Loading 3D models (glTF)

glTF / .glb is the "JPEG of 3D": the standard web format with meshes, PBR materials, textures, skeletons and animations. Export from Blender (File → Export → glTF 2.0) or download from Sketchfab/Poly Pizza. This demo loads a small sample model from the Khronos repository (needs internet).

Animations from glTF

Production asset pipeline

  • Draco / Meshopt compress geometry (DRACOLoader, MeshoptDecoder); KTX2 compresses textures. gltf-transform or gltfjsx (for R3F) automate it: npx gltf-transform optimize in.glb out.glb --compress draco.
  • Aim for under ~5 MB for a hero model on the web; fewer than 100k triangles; few materials (draw calls).
  • Reuse via model.clone() or InstancedMesh for many copies (“Physics, particles & post-processing”).
  • Free up GPU memory: geometry.dispose(), material.dispose(), texture.dispose() when removing objects.
  • Use LoadingManager to build a progress bar over many assets.

Exercises

  1. Texture a floor with a tiling PBR set (color + normal + roughness) from ambientCG; fix the color spaces.
  2. Download a free .glb from Poly Pizza, load it, center and scale it automatically, add shadows.
  3. Build a product viewer: model on a turntable, OrbitControls limits, HDRI environment, and color-variant buttons that change one material's color.
  4. Make a character play "Idle" and crossfade to "Walk" on a key press using AnimationMixer.
  5. Compress your model with gltf-transform and report the size difference.
  6. Add a loading progress bar using LoadingManager.

Checkpoint

Why does my textured model look washed out or too dark?Likely wrong color space. Color textures need SRGBColorSpace; data maps must stay linear. (GLTFLoader handles this for you.)
Why is glTF preferred?It's an open, compact, runtime-oriented format with PBR materials and animations, supported by every tool and loader.
