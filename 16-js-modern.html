Modules (import / export)

Modules split code into files with their own scope. Load them with <script type="module">. Modules are strict mode and deferred by default.

NoteModules need to be served over HTTP (use Live Server or npx vite); opening the file with file:// blocks them. Include the .js extension in browser imports. Bundlers like Vite let you import npm packages by bare name: import confetti from "canvas-confetti".

Exercises

  1. Rewrite a function taking 5 positional arguments to take one options object with destructured defaults.
  2. Write pick(obj, ...keys) and omit(obj, ...keys) using destructuring/spread/Object.fromEntries.
  3. Merge two config objects deeply (write deepMerge).
  4. Split your Lesson 15 to-do app into modules: store.js (data), view.js (DOM), main.js (wiring).

Checkpoint

Named vs default exports?Named: many per file, imported with braces by exact name. Default: one per file, imported under any name. Named exports are easier to refactor and tree-shake.
Does spread deep-copy?No. It copies one level; nested objects stay shared.
