Destructuring, spread & modules

Modern JavaScript has some compact syntax that you'll see on nearly every line of real code, especially React code. None of it lets you do anything new; it lets you write common things more briefly. This lesson goes through each piece slowly, then shows how to split a program into files with modules.

In this lesson you will

  • Unpack arrays and objects into variables with destructuring.
  • Copy and combine with spread (...), and collect leftovers with rest.
  • Update objects and arrays without changing the original.
  • Split code into files with import and export.
  • Type destructured parameters and share types between files in TypeScript.

About 50 minutes.

Rest: ... collects things up

The same three dots, used on the left side or in parameters, do the opposite: they collect "the rest" into an array or object.

Spread or rest?Same dots, opposite jobs. If ... is where values are being used (inside [ ], { } or a function call), it's spread: it spills out. If it's where values are being received (left of =, or in a parameter list), it's rest: it collects.

Modules: splitting code into files

Real programs are too big for one file. Modules let each file share specific things (export) and use things from other files (import).

  • Named exports (export const, export function) are imported with curly braces, using the same name.
  • A default export is imported without braces, and you can give it any name.
  • The path starts with ./ for files next to this one. In the browser you include the .js extension.

To use modules in a web page, load the entry file with type="module". (Modules only work when the page is served by a web server, such as VS Code's Live Server, not when opened directly as a file.)

Common mistakes
  • Destructuring something that's undefined: const { name } = undefined crashes. Use a default: function f({ name } = {}).
  • Thinking spread is a deep copy: nested objects are still shared.
  • Braces mismatch on imports: a default export imported with { }, or a named one without, gives undefined or an error.
  • Opening a module page by double-clicking the file: modules need a server.

Recap

  • Destructuring: const { a, b } = obj (by name), const [x, y] = arr (by position). Rename with { a: newName }, default with { a = 1 }.
  • Spread ... spills out: copy and combine arrays and objects, update with { ...obj, key: newValue }.
  • Rest ... collects: function f(...args), const [first, ...others] = arr.
  • Modules: export what a file shares, import it elsewhere. Named imports use { }.
  • TypeScript: type a destructured parameter after the whole pattern: ({ a, b }: Props). Use import type for types.
