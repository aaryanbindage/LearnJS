Loops

CarefulUse for…of for arrays (values). for…in iterates keys including inherited ones, so use it only for plain objects, if at all.

Worked example: FizzBuzz

Exercises

  1. Write isLeapYear(year) (divisible by 4, except centuries unless divisible by 400).
  2. Print a 5-row right triangle of * using nested loops or "*".repeat(i).
  3. Sum all numbers from 1 to 100 with a loop. Then verify with the formula n(n+1)/2.
  4. Find all prime numbers up to 50.
  5. Write a number-guessing function that takes a guess and a secret and returns "higher", "lower" or "correct".
  6. Collatz: starting from n, if even divide by 2, else 3n+1. Count steps to reach 1 for n=27.
