Lesson 9 — Transforms, transitions, animations & modern CSS

Add motion that guides attention without hurting performance or accessibility, then tour the newest CSS features.

Transforms

Functions: translate() rotate() scale() skew() and 3D variants (translateZ, rotateX, with perspective). Newer individual properties: translate, rotate, scale. Set transform-origin to pivot elsewhere.

PerformanceAnimate transform and opacity. They run on the GPU compositor. Animating width, top or margin forces layout every frame and janks.

Transitions

A transition animates between two states when a property changes. It needs a start value and an end value (so height: auto doesn't animate; use grid-row trick or interpolate-size: allow-keywords in new browsers).

Keyframe animations

Key properties: animation-name, -duration, -timing-function, -delay, -iteration-count, -direction (alternate), -fill-mode (forwards), -play-state. Respect prefers-reduced-motion.

Exercises

  1. Build a button with hover, active and focus-visible states that all transition smoothly.
  2. Create a loading spinner using only CSS keyframes (a bordered circle rotating).
  3. Build a 3D flip card (front and back faces with backface-visibility: hidden).
  4. Build a horizontal scroll-snap carousel.
  5. Animate an accordion open and closed (hint: grid-template-rows: 0fr → 1fr).
  6. Audit your animations in DevTools → Performance and make sure only transform/opacity animate.
