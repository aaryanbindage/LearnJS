Lesson 40 — Milestone: mini-capstone

Your first big integration milestone. One substantial, original, deployed product that uses everything: semantic HTML, polished CSS, solid JavaScript, a well-architected React app, and a real-time 3D experience at its heart.

The brief

Build a 3D-enhanced web application for a real or realistic problem. The 3D must serve the product, not just decorate it. Examples:

  • Interactive museum/gallery: walk or fly through rooms; click artworks for details (HTML overlay); search and filter exhibits; routes for each room.
  • Furniture / car / sneaker store: 3D configurator with variants, price updates, cart, checkout flow (mocked payments), saved designs.
  • Learning tool: a solar system, molecule, anatomy or physics explorer with lessons, quizzes, progress tracking, and shareable states in the URL.
  • Portfolio 2.0: scroll-driven 3D storytelling that still works well on a phone, with fully accessible content underneath.
  • Multiplayer toy: shared 3D space with WebSockets (e.g. PartyKit, Socket.IO) where visitors see each other's cursors/avatars.

Suggested plan (3 weeks)

  1. Week 1 — Foundations: product brief and user stories; wireframes; data model; design tokens; app shell with routing; block-out 3D scene; CI and deployment set up on day one.
  2. Week 2 — Features: 3D assets, interaction, state, forms, API/data layer, accessibility of every flow, tests alongside code.
  3. Week 3 — Polish: look-dev (materials, lighting, post), performance pass, mobile pass, error/empty/loading states, docs, usability test with 3 real people, fix what they stumble on.

Where this fits

This is a milestone, not the finish line. The remaining parts cover professional CSS, advanced TypeScript, backend and full-stack work, advanced React and 3D, and professional practice, ending with the final capstone in “Final capstone”.

Keep mastering

  • Read code daily: Three.js examples, React docs source, open-source apps.
  • Build small things constantly: one weekend project a month beats any course.
  • Teach: write a blog post or record a screencast on something that confused you.
  • Go deeper: browser internals (rendering pipeline), HTTP/caching, web security (XSS/CSRF/CSP), TypeScript advanced types, Node/databases, WebGPU, accessibility certification (IAAP).
