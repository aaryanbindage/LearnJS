Lesson 0 — Setup & how the web works

Before writing code, get your tools ready and understand what a browser actually does with it.

How the web works

A browser sends an HTTP request to a server (found via DNS from a domain name). The server returns a response, usually HTML. The browser parses the HTML into the DOM, fetches linked CSS, JS and images, applies styles, runs scripts, and paints pixels.

Install your tools

  1. VS Code (code.visualstudio.com) with the extensions Live Server, Prettier, ESLint.
  2. Node.js LTS (nodejs.org). Check with node -v and npm -v.
  3. Git. Check with git --version.
  4. Chrome or Firefox with DevTools (F12 or Cmd+Opt+I).

In your own editor, save this as index.html and open it with Live Server. Edits refresh automatically.

DevTools tour (spend 15 minutes)

  • Elements: the live DOM and computed styles. Edit anything; changes are temporary.
  • Console: type document.title = "Hacked".
  • Network: reload and see every request, status code, size and timing.
  • Sources: breakpoints. Application: storage and cookies.

Exercises

  1. In the Network tab, find the HTTP status code and Content-Type of your page.
  2. Open any big website; in Elements, delete a heading and change a color.
  3. In the Console, run document.querySelectorAll("a").length on a news site.
  4. Run git init in your folder and make a first commit.
