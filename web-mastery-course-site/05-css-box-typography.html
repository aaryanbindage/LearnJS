Lesson 5 — Box model, units, color & typography

Every element is a rectangle. Understand its layers, how sizes are measured, and how to make text look good.

The box model

Each element is a box: content → padding → border → margin.

  • box-sizing: border-box makes width include padding and border. Always set it globally.
  • Margin collapsing: vertical margins between adjacent blocks merge into the larger one. Padding never collapses.
  • display: block | inline | inline-block | none | flex | grid | contents. Inline elements ignore width, height and vertical margins.
  • overflow: visible | hidden | auto | scroll.
  • Padding shorthand order: top, right, bottom, left (clockwise). Logical versions: margin-inline, padding-block.

Math functions: calc(100% - 2rem), min(), max(), and the star of fluid design, clamp(min, preferred, max).

Color

Keep text contrast at 4.5:1 or better. DevTools shows the ratio in the color picker.

Typography

Useful properties: font-weight, font-style, text-align, text-decoration, text-transform, white-space, text-overflow: ellipsis. Also aspect-ratio: 16 / 9 and object-fit: cover for media.

Exercises

  1. Build a profile card: circular avatar (border-radius: 50%), name, bio and a button; centered, with a shadow and a hover lift.
  2. In DevTools, hover the box-model diagram and find which margins collapse in a stack of paragraphs.
  3. Make all type scale fluidly between 360px and 1200px viewports using clamp().
  4. Replicate a favorite site's header typography by inspecting it.
  5. Compare em and rem by nesting three lists with font-size: 0.9em and then 0.9rem.

Checkpoint

Why border-box?With content-box, adding padding or border enlarges the element past its declared width, which makes layout math painful. Border-box keeps the declared width as the total.
rem vs em?rem is relative to the root font size (predictable). em is relative to the element's (or parent's) font size, so it compounds when nested.
What does 65ch do?Limits line length to roughly 65 characters, which is the readable range.
