Forms

Bubbling & event delegation

Most events bubble: they fire on the target, then on each ancestor. So one listener on a parent can handle all children, including ones added later. This is called delegation.

event.target = where it happened; event.currentTarget = where the listener is attached. event.stopPropagation() stops bubbling (use rarely). Capture phase: pass { capture: true }.
