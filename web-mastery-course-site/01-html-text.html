Lesson 1 — Document structure & text

HTML describes the meaning of content. Learn the skeleton every page needs and the elements for text.

Elements

HTML is made of elements: <tag attribute="value">content</tag>. Some are void (no closing tag): img, br, hr, input, meta. Elements nest into a tree: the DOM.

The skeleton

RuleAlways add defer (or type="module") to scripts so they run after the HTML is parsed.

Text elements

Try it: add a fourth heading level, nest a list inside a list item, and wrap a word in <mark>.

Key ideas

  • Semantics over looks. <strong> means "important"; <b> is just bold. Choose by meaning and style with CSS.
  • Block vs inline. Block elements (p, div, h1, ul) start new lines. Inline ones (span, a, strong) flow within text.
  • Generic containers: div (block) and span (inline). Use only when nothing semantic fits.
  • Attributes: id (unique), class (reusable), lang, title, hidden, data-* (custom data).
  • Entities show reserved characters: &lt; &gt; &amp; &quot; &copy;.
  • Whitespace collapses: many spaces and newlines render as one space. Comments: <!-- not shown -->.

The browser fixes your mistakes

Delete a closing tag below and open the Elements panel in DevTools on your own copy. The browser silently repairs invalid HTML, which hides bugs, so validate at validator.w3.org.

Exercises

  1. Write an "About me" page: one h1, three h2 sections, a paragraph in each, a hobbies list and a quote.
  2. Show the literal text <p>Hello</p> on the page using entities.
  3. Add data-mood="happy" to a paragraph, then in the Console (element selected in Elements) run $0.dataset.mood.
  4. Validate your page and fix every error.

Checkpoint

Why only one h1, and why the lang attribute?One h1 gives the page a single clear topic for outlines, screen readers and search. lang lets screen readers choose pronunciation and lets browsers offer translation and spell-check.
When <em> vs <i>?em = stress emphasis (changes meaning); i = alternate voice (a ship name, a foreign phrase) with no added emphasis.
