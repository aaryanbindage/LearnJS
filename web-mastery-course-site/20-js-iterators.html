Lesson 20 — Iterators, generators, Map/Set & functional patterns

The last pieces of core JavaScript: better collections, lazy sequences, and patterns for writing predictable code.

Map, Set, WeakMap

Use Map instead of objects when keys aren't known strings, when you add/remove often, or need .size.

Iterators and generators

Anything usable in for…of (arrays, strings, Maps, Sets) is iterable. A generator function (function*) produces values lazily with yield and can pause between them.

Exercises

  1. Write a LRUCache class using Map (a Map remembers insertion order).
  2. Write a generator fibonacci() and use take to print the first 15 terms.
  3. Find the duplicate values in an array using a Set in O(n).
  4. Write groupBy(arr, keyFn) returning a Map of arrays.
  5. Validate a password (≥8 chars, a digit, an uppercase letter) with one regex using lookaheads.
  6. Implement zip, range and chunk as lazy generator utilities.

Checkpoint

When prefer Map over a plain object?Non-string keys, frequent adds/removes, guaranteed order, need for .size, and no prototype-key collisions.
What does lazy evaluation buy you?Work happens only when a value is demanded, enabling infinite sequences and avoiding needless computation.
