Lesson 18 — Classes, this & prototypes

Three.js is built on classes, and this trips up everyone at least once. Learn both properly.

Classes

Prefer composition over deep inheritance: build behavior by combining small objects/functions rather than long extends chains.

this

this is decided by how a function is called, not where it's written (except arrow functions, which inherit it from the surrounding scope).

Prototypes (what classes really are)

Every object has a hidden link to a prototype object. When you read a property that isn't on the object itself, JS walks up the prototype chain. class is cleaner syntax over this mechanism.

Exercises

  1. Build a Vector2 class with add, scale, length (getter), and static fromAngle. (You'll meet THREE.Vector3 in Part 5.)
  2. Build Shape → Circle/Rect with area() overrides, and a function summing areas.

  5. Re-implement new as a function using Object.create and apply.

Checkpoint

Why does passing obj.method as a callback lose this?Passing detaches the function from its object; when called plain, there's no receiver. Use bind, an arrow wrapper, or an arrow class field.
What is a prototype chain?The sequence of objects JS searches for a property, from the object itself up through its prototypes until null.
