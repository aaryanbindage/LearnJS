Lesson 17 — Asynchronous JavaScript

JavaScript runs one thing at a time, yet it fetches data, waits for timers, and responds to clicks without freezing. Understand how, then use promises and async/await fluently.

The event loop

JS has a single call stack. Slow work (timers, network, I/O) is handled by the browser; when finished, a callback is queued. The event loop pushes queued callbacks onto the stack only when it's empty. Promise callbacks (microtasks) run before timer callbacks (macrotasks).

Promises

A promise represents a future value: pending → fulfilled (value) or rejected (error).

async / await

async functions always return a promise. await pauses that function (not the whole program) until a promise settles. Errors become normal try/catch.

CombinatorResolves when…
Promise.all([…])all succeed (rejects on first failure)
Promise.allSettled([…])all finish; gives status of each
Promise.race([…])first to settle
Promise.any([…])first to succeed
Common bugarray.forEach(async …) does not wait. Use a for…of loop with await for sequential work, or await Promise.all(array.map(async …)) for parallel.

fetch

These demos call a public JSON API (jsonplaceholder.typicode.com), so you need an internet connection.

CORSBrowsers block cross-origin requests unless the server sends the right Access-Control-Allow-Origin header. If you see a CORS error, the fix is on the server (or via a proxy), not in your fetch call.

Resilience patterns

Top-level await works in modules (and in these demos). In classic scripts, wrap it in an async function.

Exercises

  1. Predict and verify the output order of a script mixing setTimeout, promises, and sync logs.
  2. Write sleep(ms), then write a loop that logs a countdown 3…2…1 with one-second gaps.
  3. Fetch 5 todos in parallel and print only the completed ones.
  4. Build a user search box that fetches as you type, debounced, ignoring out-of-date responses (use AbortController).
  5. Write promisify(fn) for Node-style callbacks.
  6. Implement Promise.all yourself using new Promise.
