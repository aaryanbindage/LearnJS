Lesson 12 — Functions, scope & closures

Functions are values: you can store them, pass them, and return them. This idea powers everything from event handlers to React.

Defining functions

A function with no return returns undefined. Missing arguments are undefined. Prefer one clear purpose per function and descriptive verbs for names (getUser, isValid).

Scope

Lexical scope: a function can see variables from where it was written, searching outward through enclosing scopes (the scope chain).

Closures

A closure is a function that remembers the variables of the scope it was created in, even after that scope has finished.

Higher-order functions

Pure functions & side effects

A pure function returns the same output for the same input and changes nothing outside itself. Pure functions are easy to test and are central to React. Mutating arguments, writing to globals, or reading the clock are side effects.
