Lesson 14 — The DOM

The Document Object Model is the browser's live tree of your page. JavaScript reads and changes it; the browser re-renders. From here on, demos are full HTML pages.

Selecting elements

Changing content, attributes, classes, styles

SecurityNever put untrusted text into innerHTML. Use textContent, or build elements with createElement. This is how XSS attacks happen.

Creating and removing elements

Other tools: cloneNode(true), insertAdjacentHTML, <template> elements, and DocumentFragment for batching many inserts.

Reading size and position

Observers (modern, efficient)

Scroll the preview. IntersectionObserver tells you when elements enter the viewport (lazy loading, scroll animations). Also see ResizeObserver and MutationObserver.

Performance habits

  • Batch DOM writes; avoid alternating reads and writes of layout properties.
  • Prefer toggling classes over many inline style assignments.
  • Cache selections you reuse in variables.

Exercises

  1. Build a counter: a number and +/− buttons that update the text.
  2. Build a "tag list": an input and Add button that appends items with a delete button each.
  3. Toggle a dark theme by toggling a class on document.documentElement.
  4. Generate a table from an array of objects using createElement (no innerHTML).
  5. Use IntersectionObserver to fade in sections as you scroll.
  6. Build a character counter for a textarea that turns red past 100.

Checkpoint

textContent vs innerHTML?textContent treats the string as plain text; innerHTML parses it as HTML (powerful but an XSS risk with untrusted input).
querySelectorAll vs getElementsByClassName?querySelectorAll returns a static NodeList; getElementsBy* returns a live HTMLCollection that updates as the DOM changes.
