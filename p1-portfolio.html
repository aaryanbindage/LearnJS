Project 1 — Responsive portfolio

Combine everything from HTML and CSS into a real, deployable personal site. No JavaScript needed.

Requirements

  1. Semantic structure: header + nav, main with sections (Hero, About, Projects, Contact), footer. One h1.
  2. Design tokens in :root: colors, spacing scale, radius, font sizes via clamp().
  3. Layout: grid for the page and the project gallery (auto-fit/minmax), flex for the navbar and cards.
  4. Responsive: mobile-first, looks right from 320px to 1600px; at least one container query.
  5. Dark mode through prefers-color-scheme and a manual override.
  6. Motion: hover/focus transitions, one keyframe animation, and a reduced-motion fallback.
  7. Accessibility: skip link, labeled contact form, visible focus, contrast ≥ 4.5:1. Lighthouse Accessibility = 100.
  8. Performance: sized images, lazy-loading, modern formats. Lighthouse Performance ≥ 90.

Stretch goals

  • Scroll-driven reading-progress bar.
  • Smooth page transitions with @view-transition.
  • Deploy to GitHub Pages or Netlify and share the link.

Self-review checklist

Can I answer yes to all of these?
  • Resizing from 320px to 1600px never causes horizontal scroll.
  • I can tab through everything and always see where focus is.
  • Changing one token (e.g., --brand) re-themes the whole site.
  • No !important, no id selectors for styling, no inline styles.
  • HTML validates with zero errors.
