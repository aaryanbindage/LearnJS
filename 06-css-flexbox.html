Lesson 6 — Flexbox

Flexbox lays items out along one axis and distributes the leftover space. It is the tool for navbars, toolbars, card rows and centering.

Play with the container

Change flex-direction, justify-content, align-items and flex-wrap and watch the boxes move.

Mental modelThe main axis follows flex-direction; the cross axis is perpendicular. justify-* works on the main axis, align-* on the cross axis. Switch to column and they swap meaning visually.

Item properties

Common values: flex: 1 (equal share), flex: none (don't flex), flex: 0 0 300px (fixed width).

Gotchas

  • Flex items default to min-width: auto, so long text can overflow. Add min-width: 0.
  • Margins don't collapse in flex containers.
  • flex-basis beats width on the main axis.
  • order changes visual order only. Keyboard and screen-reader order stay the same.

Checkpoint

What does flex: 1 1 250px mean?The item may grow (1) and shrink (1) from a starting size of 250px, so it fills available space but wraps when it can't fit.
A long word overflows a flex child. Fix?Set min-width: 0 on the child and use overflow-wrap: anywhere or overflow: hidden; text-overflow: ellipsis.
