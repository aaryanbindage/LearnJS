Strings: working with text

Names, messages, search boxes, URLs, passwords: a huge amount of programming is working with text. In this lesson you'll learn to build strings, take them apart, and transform them.

In this lesson you will

  • Write strings with quotes, and put quotes or new lines inside them.
  • Build strings from variables with template literals.
  • Get a string's length and pick out single characters.
  • Use the most common string methods: changing case, trimming, searching, cutting and replacing.
  • Use TypeScript's autocomplete to explore what strings can do.

Length and individual characters

Every string knows how many characters it has. Spaces and punctuation count too:

Notice length has no parentheses. It's a property: a piece of information the string has, not an action it does.

Each character has a position number called its index. The important, slightly weird part: counting starts at 0, not 1.

CharacterJavaScript
Index0123456789

Because counting starts at 0, the last index is always length - 1. This "off by one" idea trips everyone up at first, so it's worth re-reading that table.

For const s = "hello", what is s[1]?

Indexes start at 0, so s[0] is "h" and s[1] is "e".

Strings never change; methods give you new ones

This is an important detail. String methods don't change the original string. They give you back a new string, and the original stays as it was:

The technical word is immutable: a string can't be modified, only replaced.

Chaining methods

Since each method gives back a new string, you can call another method on the result straight away. This is called chaining, and it reads left to right:

Step by step: trim() gives "Hello World", toLowerCase() gives "hello world", replaceAll gives "hello-world". That's how websites turn a blog post title into a web address (called a "slug").

Common mistakes
  • Forgetting to store the result: name.trim(); on its own does nothing useful. Write name = name.trim();.
  • Parentheses on length: it's word.length, not word.length().
  • Missing parentheses on methods: word.toUpperCase without () doesn't run the method. It just refers to it.
  • Using normal quotes for a template: "Hi ${name}" prints the ${name} literally. Template slots only work in backticks.

Recap

  • Strings use ", ' or `. Escape special characters with \; \n is a new line.
  • Template literals (backticks) with ${value} are the best way to build strings.
  • .length gives the number of characters. Indexes start at 0; the last is length - 1.
  • Key methods: toUpperCase, toLowerCase, trim, includes, indexOf, slice, replace, split.
  • Strings are immutable: methods return new strings, so store the result.
  • In TypeScript, press Ctrl + Space after a dot to explore methods, and hover to see result types.

What's the index of the last character of a string s?s.length - 1, because indexes start at 0. Or use s.at(-1) to get the character directly.
Why doesn't name.trim(); change name?Strings are immutable. trim() returns a new string; you have to store it: name = name.trim();.
What does `2 + 2 = ${2 + 2}` produce?The string "2 + 2 = 4". The part outside ${} is plain text; the part inside is calculated.
