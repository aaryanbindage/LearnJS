Lesson 46 — SVG & Canvas 2D graphics

Before and beside 3D, the web has two 2D graphics systems with opposite strengths. SVG is a retained scene of DOM elements; Canvas is an immediate-mode pixel surface. Knowing which to use is half the skill.

SVG

SVG is XML drawn in resolution-independent vector shapes. Every shape is a real DOM element you can style with CSS, animate, make clickable and describe for screen readers.

  • viewBox="minX minY width height" defines the internal coordinate system; the SVG scales to its CSS size. Always set it.
  • Shapes: rect circle ellipse line polyline polygon path text; structure: g (group), defs, use, symbol, clipPath, mask, linearGradient, filter.
  • path commands: M move, L line, C cubic Bézier, Q quadratic, A arc, Z close (lowercase = relative).
  • Style with CSS (fill, stroke, currentColor); animate with CSS, WAAPI, GSAP; draw-on effects with stroke-dasharray/offset.
  • Inline SVG icons inherit text color via fill="currentColor". Optimize files with SVGO/SVGOMG.
  • Add role="img" + <title>, or aria-hidden="true" for decorative graphics.

Canvas 2D

A <canvas> is a bitmap you draw on with JavaScript. It has no objects: once drawn, pixels are just pixels. That makes it fast for thousands of moving things (particles, games, image processing) and awkward for interaction and accessibility.

Exercises

  1. Draw an analog clock in SVG with CSS-animated hands driven by the real time.
  2. Write a function that turns an array of numbers into a smooth SVG line chart path (use Catmull-Rom or cubic curves), with hover tooltips and accessible labels.
  3. Animate a self-drawing logo using stroke-dasharray and getTotalLength().
  4. Build a canvas drawing app: brush, eraser, color, undo (keep a stroke list and redraw), and export to PNG.
  5. Build Pong or Snake with a fixed-timestep game loop on canvas.
  6. Apply a per-pixel grayscale/blur filter to an image using getImageData, then move it into a Worker with OffscreenCanvas.

Checkpoint

When SVG, when Canvas?SVG for crisp, interactive, accessible graphics with modest element counts; Canvas when you draw very many items or need pixel-level control and animation performance.
Why multiply canvas.width by devicePixelRatio?The canvas backing store is in device pixels; without scaling it, graphics are upscaled and blurry on high-DPI screens.
