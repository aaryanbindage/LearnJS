Lesson 37 — React Three Fiber & drei

Combine Parts 5 and 6. React Three Fiber (R3F) is a React renderer for Three.js: your scene becomes JSX, state drives 3D, and you get components, hooks and the whole React ecosystem.

Setup

VersionsR3F v8 pairs with React 18; R3F v9 pairs with React 19. Install the one that matches your React version (check npm ls react) and see the R3F docs (r3f.docs.pmnd.rs) for current details.

The hooks

The #1 R3F ruleNever setState every frame. React re-rendering 60×/second is slow. In useFrame mutate refs and Three objects directly (ref.current.position.x += …). Use React state only for discrete changes (selected, hovered, mode).

Suspense, loading and the drei toolbox

Shared state with Zustand (UI ↔ 3D)

Context from outside the <Canvas> is not available inside it (it's a separate React renderer). A store like Zustand, or re-providing the context inside, bridges the gap.

Performance in R3F

  • frameloop="demand" + invalidate() renders only when something changes (great for configurators and dashboards).
  • Reuse geometry and materials; <Instances> / InstancedMesh for many copies.
  • Don't create objects in render: useMemo(() => new THREE.Vector3(), []) or module-level constants.
  • <Preload all />, <AdaptiveDpr />, <PerformanceMonitor />, <Bvh>.
  • Convert models to components with npx gltfjsx model.glb --transform (optimized + typed JSX).
  • Inspect with r3f-perf and the Spector.js / Chrome Performance tools.

Next.js and SSR

Canvas needs the browser. In Next.js mark the component "use client" and/or load it with dynamic(() => import("./Scene"), { ssr: false }).

Checkpoint

Why not store a rotating object's angle in useState?It would trigger a React re-render every frame. Mutate the Three object's rotation in useFrame via a ref instead.
What does args do?It passes constructor arguments to the underlying Three.js class, e.g. args=[1,2,3] for BoxGeometry(1,2,3). Changing args recreates the object.
