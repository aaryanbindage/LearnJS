Lesson 21 gave you a taste. Now learn TypeScript as a daily tool: how the type system thinks, how to model real data, and how to configure it for safety. Practice every snippet in the TypeScript Playground (typescriptlang.org/play) or a Vite react-ts project.

Mental model

  • TypeScript is a static analyzer: it checks code before it runs, then erases types. It adds no runtime behavior and no runtime validation.
  • Types are structural ("duck typing"): two types are compatible if their shapes match, regardless of names.
  • Prefer inference for local variables; annotate boundaries (function parameters, exported APIs, data from outside).

Types at the boundaries: runtime validation

Key insightTypes vanish at runtime. Data from fetch, localStorage, form input and JSON.parse is unknown no matter what you claim. Validate it with a schema library, and derive the static type from the schema so they can't drift.

TypeScript with React

Practical rules

  1. Avoid any. Use unknown + narrowing or generics.
  2. Avoid type assertions (as) and non-null assertions (!); each is a promise you can break. Prefer guards and validation.
  3. Model states with discriminated unions, not bags of optional booleans.
  4. Let inference work; don't annotate what the compiler already knows.
  5. Don't fight the compiler with clever types. If a type takes 20 minutes to write, the design is probably too clever.
  6. Use satisfies to check a value matches a type while keeping its narrow inferred type: const cfg = { port: 3000 } satisfies Config;

Exercises

  1. Convert your Project 2 (vanilla app) to TypeScript with strict and noUncheckedIndexedAccess. Fix every error properly, without any.
  2. Model an AsyncState<T> discriminated union and write an exhaustive switch renderer.
  3. Write a generic typed fetchJson<T>(url, schema) that validates with Zod and returns a Result instead of throwing.
  4. Write a type-safe EventEmitter<Events> where on("login", payload => …) infers the payload type from an event map.
  5. Type a polymorphic React Button that renders as a button or an a based on href.
  6. Use tsc --noEmit in CI so type errors fail the build.
