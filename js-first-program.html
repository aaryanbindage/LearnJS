Your first program

In this lesson you will

  • Use the code editors on this site: edit, run, and read the output.
  • Print things with console.log().
  • Write comments, and learn to read error messages without panicking.

About 30 minutes. Type the examples yourself. Don't just read them.

What is a program?

A program is a list of instructions for a computer. The computer does them one at a time, from top to bottom, exactly as written. It doesn't guess what you meant.

AnalogyA program is like a recipe. "Crack two eggs. Whisk them. Pour into the pan." Each line is one step, done in order. The difference is that a computer follows the recipe literally. If you write "whisk the egs", it stops and says it doesn't know what "egs" are.

The language we'll write those instructions in is JavaScript (often shortened to JS). Every web browser can run it. It's what makes web pages interactive: menus that open, forms that check what you typed, games, maps, chat apps.

Soon you'll also meet TypeScript (TS). TypeScript is JavaScript with an extra safety layer that catches mistakes before your code runs. You'll learn both side by side, starting two lessons from now. Everything you learn about JavaScript is also true in TypeScript.

Taking console.log apart

That one line has several pieces. Here's what each one does:

PieceWhat it means
consoleThe console: a text area where programs can print messages. On this site, it's the box under the editor.
.The dot means "inside" or "belonging to". console.log means "the log thing that belongs to console".
logThe action: write a line to the console ("log" as in a ship's log or a diary).
( )The parentheses mean "do it now", and hold what you want to print.
"Hello, world!"The text to print. Text goes inside quotes so JavaScript knows it's text, not code.
;A semicolon marks the end of an instruction, like a full stop ends a sentence. JavaScript usually works without it, but we'll include it to keep things clear.

An instruction like this is called a statement. Programs are made of statements.

A piece of text in quotes is called a string (think "a string of characters"). You can use double quotes "like this" or single quotes 'like this'. Just start and end with the same kind.

What does console.log("10" + "5"); print?

Both are strings, because both are in quotes. When you use + on two strings, JavaScript glues them together: "10" followed by "5" is "105". Gluing strings is called concatenation. You'll see a lot more of this in the Strings lesson. Try it in an editor above to check.

Comments: notes for humans

A comment is text the computer ignores. You write comments to explain your code to other people, or to yourself next week.

Handy trickTo switch a line off without deleting it, put // in front of it. This is called "commenting out" a line. In the editor, select a line and press Ctrl + / (Cmd + / on a Mac) to toggle it.

Errors are normal (and helpful)

Every programmer, including those with decades of experience, makes mistakes all day. When the computer can't follow an instruction, it stops and shows an error message. An error isn't a failure. It's the computer telling you exactly what confused it.

The console shows something like ReferenceError: consol is not defined (line 2), and the broken line is highlighted in red. Let's read that message:

  • ReferenceError is the kind of error. A reference error means "you mentioned a name I don't know".
  • consol is not defined is the details: it doesn't know anything called consol, because it's spelled wrong.
  • line 2 tells you where to look.

Notice that the first line still printed, but the third didn't. When JavaScript hits an error, it stops right there. Fix the typo (add the missing e) and run it again.

Common mistakes
  • Capital letters matter. Console.log and console.LOG don't work. JavaScript is case-sensitive: console and Console are completely different names to it.
  • Missing quote or bracket. console.log("hi); is missing its closing quote. The editor underlines the problem with a red squiggle before you even run it.
  • Curly "smart" quotes. If you copy code from a word processor, “hi” might sneak in. Code needs straight quotes: "hi".

Recap

  • A program is a list of instructions (statements) that run from top to bottom.
  • console.log(...) prints a value to the console. Use commas to print several.
  • Text in quotes is a string. Numbers have no quotes and can do math.
  • // starts a comment; /* ... */ wraps a multi-line comment.
  • Error messages tell you what went wrong and which line. Read them; they're on your side.

Check your understanding

In what order do statements run?Top to bottom, one at a time, unless something (like an error) stops the program.
What's the difference between 5 and "5"?5 is a number you can do math with. "5" is a string: a piece of text that happens to contain the character 5.
An error says ReferenceError: conole is not defined. What do you check first?The spelling of the name it mentions. Here conole should be console.
