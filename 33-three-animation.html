Lesson 33 — Animation loop, transforms & controls

Make the scene move at a consistent speed on any machine, understand the scene graph's transforms, and let users explore with the mouse.

Transforms and the scene graph

Every Object3D has position (Vector3), rotation (Euler, radians) or quaternion, and scale. Children are positioned relative to their parent, so moving a parent moves everything inside it. This is how you build solar systems, robot arms and character rigs.

Rotations apply in order X→Y→Z by default, which can cause gimbal lock. For arbitrary orientation or smooth interpolation use quaternions: q.slerp(target, 0.1).

The render loop and delta time

Machines run at different frame rates (60, 120, 144 Hz). If you move "0.1 per frame", a fast monitor makes things faster. Multiply by the time since the last frame (delta time) to make motion framerate-independent.

renderer.setAnimationLoop is preferred over a manual requestAnimationFrame (it also supports WebXR) and pauses when the tab is hidden.

Easing and smoothing

For timelines, sequences and easing curves use GSAP (gsap.to(mesh.position, { x: 3, duration: 1, ease: "power2.inOut" })), or Three's built-in AnimationMixer for baked clips (Lesson 34).

Controls and a debug GUI (live)

Drag to orbit, scroll to zoom, right-drag to pan. The panel changes values live.

Other controls

  • TrackballControls, FlyControls, PointerLockControls (first-person), MapControls, TransformControls (gizmo for moving objects), DragControls.
  • CameraControls (yomotsu) and drei's <CameraControls/> add animated fly-to transitions.
  • Clamp OrbitControls for product viewers: minDistance, maxDistance, maxPolarAngle, enablePan = false.

Exercises

  1. Add Mars and Jupiter with different orbit radii and speeds; add a faint orbit ring (RingGeometry or LineLoop) for each.
  2. Prove delta time works: temporarily add an artificial slowdown and show rotation speed doesn't change.
  3. Make a camera that smoothly follows a moving object using lerp/damp.
  4. Build an on-screen WASD + mouse-look fly camera using PointerLockControls.
  5. Use gsap to animate the camera between three "scenes" when buttons are clicked.
  6. Add TransformControls so you can drag cubes around with an axis gizmo.
