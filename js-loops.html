Loops: repeating code

Computers are brilliant at doing the same thing over and over without getting bored. A loop runs a block of code many times, so you can count to a million, go through every item in a list, or keep a game running, with only a few lines of code.

In this lesson you will

  • Repeat code while a condition is true with while.
  • Count with the for loop, and understand each of its three parts.
  • Go through every character of a string with for...of.
  • Build up a result inside a loop (totals, counts, new strings).
  • Stop early with break, skip with continue, and avoid infinite loops.

About 50 minutes. This is a big idea, so take breaks.

The while loop

A while loop looks just like an if, with one difference: when the block finishes, it goes back and checks the condition again. It keeps going round as long as the condition is true.

Let's trace it. Each trip through the block is called an iteration:

Every loop needs three things
  1. A starting point (let count = 1)
  2. A condition to keep going (count <= 5)
  3. A step that moves towards the end (count = count + 1)
If the step is missing or goes the wrong way, the loop never ends.

The parentheses hold three parts, separated by semicolons:

PartCodeWhen it runs
Startlet i = 1Once, before the loop begins
Conditioni <= 5Before every iteration. If false, the loop ends.
Stepi++After every iteration (i++ means add 1)

The counter is traditionally called i (for "index"). It's one of the few places where a one-letter name is normal.

The step can be anything, not just i++:

How many times does this print? for (let i = 0; i < 3; i++) { console.log("hi"); }

i takes the values 0, 1 and 2. When it reaches 3, 3 < 3 is false, so the loop stops. Starting at 0 and using < is the most common pattern: it runs exactly that many times.

Common mistakes
  • Off by one: i <= word.length goes one past the end. With indexes starting at 0, use i < length.
  • Infinite loops: forgetting the step, or stepping the wrong way (i-- when counting up).
  • Resetting the accumulator inside the loop: if let total = 0 is inside the braces, it starts from zero on every iteration.
  • Commas instead of semicolons in the for header: it's for (let i = 0; i < 5; i++).

Recap

  • while (condition) { ... } repeats as long as the condition is true.
  • for (start; condition; step) { ... } is the standard counting loop. for (let i = 0; i < n; i++) runs n times.
  • for (const x of something) goes through each item: each character of a string, and soon each item of an array.
  • Build results with an accumulator made before the loop.
  • break leaves the loop; continue skips to the next iteration.
  • Every loop needs a way to end. TypeScript infers loop variable types and catches accumulators of the wrong type.
